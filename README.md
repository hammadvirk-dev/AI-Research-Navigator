# AI-Research-Navigator 🌐
> **Stop Googling, Start Discovering.**
> 
AI-Research-Navigator is a Python-based automation tool designed for deep-dive research. It bypasses the manual labor of scrolling through search results by automatically fetching data, cleaning it, and using the **Gemini 2.5 Flash** model to synthesize a structured, cited research report.
## 🚀 Key Features
 * **Automated Multi-Source Synthesis**: Aggregates data from multiple top-tier web sources.
 * **AI-Powered Analysis**: Uses advanced LLM logic to remove duplicates and identify conflicting viewpoints.
 * **Citation Management**: Automatically links facts to their original sources for academic or professional integrity.
 * **Bias Detection**: Highlights different perspectives on controversial or complex topics.
 * **Markdown Export**: Generates clean, ready-to-publish reports.
## 🛠️ Setup Guide
### 1. Prerequisites
Ensure you have Python 3.9+ installed.
### 2. Install Dependencies
```bash
pip install -r requirements.txt

```
### 3. Get Your API Key
 1. Visit the Google AI Studio.
 2. Generate a free API Key.
 3. Set it as an environment variable:
   ```bash
   # Windows
   set GEMINI_API_KEY='your_api_key'
   
   # Linux/macOS
   export GEMINI_API_KEY='your_api_key'
   
   ```
### 4. Run the Tool
```bash
python research_navigator.py

```
## 📖 Use Cases
 * **Students**: Generate literature reviews and find primary sources faster.
 * **Bloggers/Content Creators**: Gather facts and diverse opinions for deep-dive articles.
 * **Market Researchers**: Track competitors and industry trends without manual searching.
